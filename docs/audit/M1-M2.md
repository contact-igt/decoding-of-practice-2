# M1 and M2 · Landing page and interactive content

**PASS** for the locally rendered experience and interaction tests.

The landing page uses a photographic hero, programme and problem framing, four learning pillars, a fictional case journey, programme summary, curriculum, documentary classroom photography, faculty profile, audience guidance, intended outcomes, admissions, FAQs and closing contacts. Testimonial, approved brochure, current faculty assignment and AI content are configurable. Unapproved testimonials, AI, fee details, certificates and dates stay out of the page.

The legal workflow, curriculum and FAQs use HTML disclosures. The enquiry uses two steps with back navigation, shared validation, visible field errors, consent and an honest unavailable state. Headline variants share one server-rendered route. The local confirmation path requires a signed receipt.

Files are `app/decoding-of-practice/`, `app/globals.css`, `components/site.tsx`, `components/admission-form.tsx`, `lib/course.ts` and `public/vls/`. See [M5](M5.md) for rendered verification and screenshots.
