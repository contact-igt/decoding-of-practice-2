# M5 · Browser, accessibility and performance

## Browser acceptance

**PASS** on the production build. `DOP_LOCAL_TEST=1 npm start -- --port 3001` and `DOP_TEST_ORIGIN=http://127.0.0.1:3001 npm run test:browser` exercised Playwright using headless Chrome.

- Layout, hero action visibility, anchors, decoded images and clean console checks passed at 320, 375, 390, 430, 768, 1024, 1440 and 1920px.
- Mobile navigation works with keyboard and Escape. Case, curriculum and FAQ disclosures operate by keyboard. The case journey also works with JavaScript disabled.
- Enquiry tests covered invalid data, back navigation, consent, transient failure, same-key retry, local receipt, refresh, unverified direct visits, concurrent duplicates, conflicting keys, rejected origin, oversized requests and honeypot rejection. First/latest attribution survived the campaign flow. Test acceptance did not emit a live conversion event.
- Axe returned zero WCAG 2 and 2.1 level A/AA violations for the initial page at 390px and 1440px and for step two of the form at 390px.
- Full-page visual review covered typography, photography, heading rhythm, sticky controls, the admissions form and the footer. Captures measure 390×11,933 and 1440×9,654.

## Lighthouse lab

Lighthouse 13.6.0 and Headless Chrome 158 measured the production build on loopback. The separate release test profile ran on port 3002 with the proposed academy origin and indexing enabled to exercise production SEO output. The local development and staging defaults remain noindex. No external requests appeared in the final Lighthouse traces.

| Profile | Performance | Accessibility | Best Practices | SEO | LCP | CLS | TBT |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Mobile, three runs | 97 | 100 | 100 | 100 | 2.61–2.63 s | 0 | 1.0–7.6 ms |
| Desktop | 100 | 100 | 100 | 100 | 0.54 s | 0 | 0 ms |

**PASS** on Lighthouse score targets and lab CLS. **FAIL** on the 2.5-second mobile lab LCP target by 0.11–0.13 seconds. Explicit image priority, synchronous hero decode and a preloaded, variable Inter font reduced the observed initial mobile LCP from about 2.9 seconds. Field LCP, CLS and INP are unmeasured. TBT is a lab measurement and does not report field INP.

Reproduce with Lighthouse CLI 13.6.0 against the local release-profile URL using `--only-categories=performance,accessibility,best-practices,seo`. Add `--preset=desktop` for desktop. Local acceptance requires no deployment or crawler registration.
